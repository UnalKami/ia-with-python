# AI From Scratch

This repository is a hands-on learning project focused on understanding how AI models work by building knowledge and implementations from the ground up.

The goal is to progress from the fundamentals of Python and machine learning to eventually building an AI model, documenting the learning process along the way.
```
🚧 This repository is a work in progress.
```
## Goals

The main goal of this repository is to understand the foundations behind AI models instead of only using high-level libraries.

The learning path will progressively cover:

- Python fundamentals
- Mathematics for Machine Learning
- Machine Learning fundamentals
- Neural Networks
- Deep Learning
- Modern AI architectures
- Building a model from scratch

## Environment

The project currently uses:

- Python 3.13
- venv
- pip
- VS Code

### Setup

Create the virtual environment:

python3.13 -m venv .venv

Activate it:

source .venv/bin/activate

Check the Python version:

python --version

Install the project dependencies:

pip install -r requirements.txt
